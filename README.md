# City King Brilliance

Build a premium, production-ready, fully responsive FMCG spice brand website for:

Company: Sah Food Industries
Brand: City King Spices / City King Masala
Location: Siliguri, Darjeeling, West Bengal, India
Owner: M. Sah
Primary contact: +91 98004 92817

This is a real Indian masala/spice business. The website must feel like a professionally established FMCG brand website — NOT like a generic local business template, NOT like a basic portfolio website, and NOT like a directory listing.

The goal is to create a WOW-level first impression for the client.
